Site Diff Inspector

Crawls a benchmark site and a candidate site with a real headless browser, matches pages by path (URL after the domain), then diffs visible page content and candidate link health page‑by‑page. Comparison ignores markup, scripts, and tracking-tag noise — it checks what a reader actually sees.
Diff Inspector Site Analysis History
Rendering runs server-side via Crawlee + Playwright (a real headless Chromium — captures JS-rendered content, not just raw HTML) and links are checked with Linkinator. Crawling seeds from the site's sitemap first (falls back to link-following if there isn't one), so counts reflect the real site, not just what's linked from the homepage. Crawling a large site takes a while because it actually renders every page — this is expected. Prefer to check specific pages instead of a whole site? Switch either panel to Use a URL list and paste or upload exactly the URLs you want compared — no crawling happens in that mode, and pages are paired by position (1st benchmark URL vs 1st candidate URL, and so on) rather than by matching path, so the two lists can be on entirely different domains.
